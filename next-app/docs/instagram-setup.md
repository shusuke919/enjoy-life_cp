# Instagramの写真をサイトに表示する設定

トップページのInstagramセクションに、投稿写真を最大6枚並べる機能の設定手順です。

設定しなくてもサイトは正常に動きます。その場合は写真が出ず、Instagramへのリンクカードだけが
表示されます。取得に失敗したときも同じ表示に戻るため、**設定ミスやトークン切れでサイトが
壊れることはありません**。

## 前提

- Instagramアカウントが**プロアカウント**（ビジネスまたはクリエイター）であること
  - 個人アカウントではAPIを使えません。Instagramアプリの「設定 > アカウントの種類とツール」から無料で切り替えられます
- Meta（Facebook）の開発者アカウント

> 以前使われていた Instagram Basic Display API は2024年12月に廃止されました。現在の正規ルートは
> **Instagram API with Instagram Login** です。Metaは仕様変更が多いため、作業前に
> [公式ドキュメント](https://developers.facebook.com/docs/instagram-platform)で最新の手順を確認してください。

## 手順

### 1. Meta開発者アプリを作る

1. https://developers.facebook.com/apps/ で「アプリを作成」
2. アプリタイプは **ビジネス（Business）** を選ぶ
   - 既存のアプリがビジネス型でない場合は、新しく作り直す必要があります
3. 作成後、製品として **Instagram** を追加する

### 2. アクセストークンを発行する

1. アプリのダッシュボードで **Instagram > API setup** を開く
2. 対象のInstagramアカウント（@peaceyao_gh）を接続する
3. 必要な権限（スコープ）は **`instagram_business_basic`** のみ
   - 投稿の一覧と画像URLの取得にはこれで足ります。投稿機能などの権限は不要です
4. 「アクセストークンを生成」でトークンを発行する
   - `IGAA` で始まる長い文字列です
   - **ダッシュボードから発行したトークンは最初から長期（60日）です。**
     ログインフローで取得したトークンは1時間で切れるので、必ずダッシュボードから発行してください
   - 自分のアカウントのデータを読むだけなので、アプリ審査は不要です

> **トークンは password と同じ扱いにしてください。** チャットやメールに貼らず、
> 下記の環境変数に直接入力してください。

### 3. 環境変数に登録する

**本番（Vercel）**

Project Settings > Environment Variables に追加します。

| Key | Value |
| --- | --- |
| `INSTAGRAM_ACCESS_TOKEN` | 発行した長期トークン |

登録したら再デプロイすると反映されます。

**ローカル**

`.env.example` を `.env.local` にコピーして、`INSTAGRAM_ACCESS_TOKEN` に値を入れます。
`.env*` は `.gitignore` 済みなので、リポジトリには入りません。

## トークンの有効期限（重要）

長期トークンの有効期限は **60日** です。切れると写真が出なくなり、リンクカードだけの表示に戻ります。

期限を延ばすには、期限が切れる前に更新の要求を送り、**返ってきた新しいトークンを環境変数に
入れ直す**必要があります。

```
GET https://graph.instagram.com/refresh_access_token
  ?grant_type=ig_refresh_token
  &access_token=<現在のトークン>
```

自動更新の仕組みは今回は入れていません。更新後のトークンを保存する場所（Vercelの環境変数は
コードから書き換えられないため、KVなどの保管先）が別途必要になり、この規模のサイトでは
維持の手間に見合わないためです。

運用方法は次のどちらかをおすすめします。

- **2ヶ月ごとにカレンダーに登録して手動で更新する**（追加サービス不要）
- 写真の更新頻度が低いなら、**API連携をやめて写真を手動で差し替える**（トークンの管理が不要になる）

自動更新が必要になった場合は、保管先（Vercel KV / Upstash Redis など）を決めたうえで
Vercel Cronから定期実行する形にできます。

## 表示の仕様

- 取得件数は6件（`app/components/Instagram.tsx` の `fetchInstagramPosts(6)`）
- 取り直しは1時間ごと（`app/lib/instagram.ts` の `REVALIDATE_SECONDS`）
  - InstagramのCDNのURLには有効期限があるため、長く持ちすぎない設定にしています
- 動画・リールはサムネイルを表示し、右上に再生マークを出します
- 写真をクリックすると、その投稿のページが別タブで開きます
- 代替テキスト（読み上げ用）はキャプションから自動生成します。ハッシュタグは除き、60文字で切ります

## うまく表示されないとき

写真が出ない場合、サーバーのログに `[instagram]` で始まる行が出ています。

| ログ | 原因と対処 |
| --- | --- |
| `投稿の取得に失敗しました` + `status: 400` | トークンの失効または誤り。発行し直してください |
| `投稿の取得に失敗しました` + `status: 403` | 権限（スコープ）不足。`instagram_business_basic` が付いているか確認 |
| `想定外の配信元だったため写真を除外しました` | Meta側が新しいCDNホストを使い始めた可能性。ログの `host` を `next.config.ts` の `remotePatterns` と `app/lib/instagram.ts` の `ALLOWED_IMAGE_HOSTS` に追加してください |
| ログが何も出ない | `INSTAGRAM_ACCESS_TOKEN` が未設定。設定後に再デプロイが必要です |
